# Русский дореформенный перевод (`rpr`)

Рабочее название подхода: «Русскій техническій языкъ образца 1900 года». Добавлен 19 октября 2026 в рабочую копию `base`; каталог публикационных исходников GitHub не изменялся.

Файл: `src/client/resources/assets/litematicainventories/lang/rpr.json`. Он покрывает все 137 ключей английского оригинала и сохраняет порядок `%s`, прочих подстановок и `%%`. Имена Litematica, Minecraft и обозначения клавиш остаются узнаваемыми. Выбор производится штатным языком Minecraft «Русскій дореформенный (Россійская имперія)» — код `rpr`, не `rpr_ru`. В ресурсы Minecraft 26.3 этот язык уже включён; отдельная регистрация в моде не требуется.

## Терминологические решения

| Понятие | Перевод |
| --- | --- |
| schematic | чертёжъ; по чертежу; въ чертежѣ |
| preview | предварительный осмотръ |
| overlay | накладное изображеніе; в коротких кнопках «накладное изобр.» |
| placement | размѣщеніе чертежа |
| inventory у контейнера | содержимое |
| inventory у игрока | запасъ при себѣ / при себѣ |
| resources | припасы |
| components | свойства |
| slot | ячейка |
| comparison | сличеніе по ячейкамъ |
| cache | временное хранилище; временныя записи |
| snapshot | наблюденіе / запись |
| synchronization | согласованіе |
| settings | установки |
| ender chest | Эндеръ-ларецъ — совпадает с названием предмета в штатном `rpr` Minecraft 26.3 |

«Группа» и «координаты» сохранены: это не новые компьютерные заимствования. Английские Strict/Aggregate (после удаления переключателя), placement, preview и современная калька «слот» в переводе не используются. У слов, обозначающих современную технику, нет искусственно заявленной исторической аттестации. Например, «накладное изображеніе», «подсвѣтка» и «согласованіе содержимаго» здесь являются понятными функциональными обозначениями для игры, а не цитатами из руководства 1900 года. Понятие HUD в собственных 137 строках мода отдельно не называется; перевод не переопределяет строки самой Litematica или других модов.

## Правописание и источники

Проверялись смысловое различие `міръ` (игровой мир) и `миръ`, окончания существительных на `-ѣ`, `і` перед гласными и `й`, конечный `ъ`, `-аго/-яго` и множественное `-ыя/-ія` при существительных женского и среднего рода. Примеры выбора: `мѣсто`, `себѣ`, `всѣ`, `извѣстно`, `отмѣченныя хранилища`, `выбранныя хранилища`, `содержимаго`. Буква `ё` сохранена для ясности, в том числе в заданном пользователем `чертёжъ`; она существовала до реформы. Для `ѳ` в текущих строках нет подходящего слова, поэтому она не добавлялась ради внешнего вида.

Использованные справочные материалы:

1. [Справочник по орфографии русского языка до реформы 1918 г.](https://azbyka.org/otechnik/Spravochniki/spravochnik-po-orfografii/) — предоставленный пользователем справочник: разделы о гласных, существительных, прилагательных, местоимениях, глаголах и предлогах. Это практическая сводка, а не самостоятельное доказательство датировки компьютерного термина.
2. [Я. К. Грот. Русское правописание (первое издание 1885; дореформенный текст)](https://ru.wikisource.org/wiki/Русское_правописание_(Грот)/ДО) — историческое руководство, правила букв и окончаний. Электронный текст содержит отдельные опечатки; использовались правила, не механическое копирование всех написаний.
3. Штатные ресурсы Minecraft **26.3**, `minecraft/lang/rpr.json`: подтверждены код и название языка, `Эндеръ-ларецъ`, написание управляющих подписей. Это источник совместимости с игрой, не исторический словарь.

Словарные статьи Даля «Сличать», «Усчитывать» и «Перечерчивать» второго издания также найдены в дореформенной электронной выдаче; полные страницы при этой проверке возвращали ошибку загрузки. Они не выдаются за полностью сверенные сканы. Никакой независимой филологической экспертизы перевода не проводилось.

## Границы изменения

Перевод добавлен без изменения алгоритмов и версии. Последующим запросом пользователя удалён режим сличения всего содержимого; осталось сравнение по ячейкам. Вместе с переключателем удалены три устаревших ключа во всех языках. Обычные `ru_ru` и `en_us` не заменяются. Динамические имена предметов берутся из выбранного языка Minecraft, пользовательские названия и содержимое чертежей не переписываются.

Готовая рабочая сборка после `gradlew build` находится в `build/libs`. Это локальное дополнение к исходникам 1.1.0, а не автоматически опубликованный новый релиз. Исторический архив передачи и его манифест описывают прежний снимок и не пересоздавались.
